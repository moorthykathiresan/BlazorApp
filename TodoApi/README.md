# TodoApi

This is an ASP.NET Core WebAPI project scaffolded with `dotnet new webapi`. It includes default controllers and is ready for further development.

## How to Run

1. Build the project:
   ```bash
   dotnet build
   ```
2. Run the project:
   ```bash
   dotnet run
   ```

The API will be available at `http://localhost:5000` (or the port specified in launchSettings.json).
